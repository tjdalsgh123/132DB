# 132총국 관리시스템 ((주)와이즈교육)

- 주소: https://132db.tjdalsgh123.workers.dev
- 호스팅: Cloudflare Workers (정적 자산) — `wrangler.jsonc`
- 화면: **React 18 + Vite** (`src/`) → 빌드하면 `dist/` 로 만들어져 배포됨
  - `src/main.jsx` 시작 · `src/App.jsx` 로그인·메뉴·화면 전환 · `src/pages/*.jsx` React 화면
  - `src/lib/` 공통 (Supabase 연결·데이터·권한·월급 계산 엔진·엑셀·그래프)
  - `src/legacy/` 아직 React로 옮기는 중인 기존 화면 (React 안에서 그대로 동작)
  - `public/` 그대로 복사되는 파일 (글꼴·로고·`_headers`)
- 내 컴퓨터에서 실행: `npm install` → `npm run dev` (http://localhost:5173 · 개발 DB 사용)
- DB: Supabase 「132총국 DB」 — 웹앱은 `app_*` 함수만 호출 (권한·범위는 DB 함수가 확인)
- 로그인: Supabase Auth 이메일+비밀번호 (회원가입 막음, 관리자가 계정 생성)

## 진행 상황
- 1단계: 로그인·권한 SQL (14_webapp_auth.sql) ✅
- 2단계: 로그인 화면, KDC 매출 등록(홍보팀장·지국 직할), 자율학기제 매출 등록, 내 계정(비밀번호 변경) ✅
- 3단계: 전체 화면 웹앱 이전 ✅
  - 공통: 대시보드, 수당계산기
  - 홍보팀장: KDC 매출 등록, 자율학기제 매출 등록, 매출 현황(엑셀), 월급 계산
  - 지국장: 직할 매출 등록, 지국 매출 현황(엑셀), 홍보팀장 관리, 지국장 월급 계산
  - 관리자: 권한 관리(사람·로그인 계정·역할·지국), 수당 관리, 수당 현황, 수당 등록, 로그 관리, 메뉴 관리
  - 첫 로그인 시 임시 비밀번호 변경 강제

## 월급 마감 (20_payroll_close.sql)
- 「관리자 → 월급 마감」에서 월급 월마다 「마감할 금액 계산하기」 → 확인 → 「이 금액으로 마감」
- 마감한 달: 홍보팀장·지국장·총국장 월급이 저장된 확정 금액으로 보임 (수당 기준·매출이 바뀌어도 그대로)
- 마감한 달에 들어가는 매출은 잠김: 상품(KDC 등) 매출 = 월급 월 − 2개월 · 자율학기제 = − 1개월 · 월 입력값 = 그 달
- 고쳐야 하면 관리자가 「마감 풀기」 (확정 내역은 로그에 남음) → 고친 뒤 다시 마감

## React 전환 진행

- 2단계 ✅ 대시보드, 총국장 대시보드, 로그 관리, 월급 마감(신규)
- 3단계 ✅ 매출 등록·자율학기제·매출 현황·홍보팀장 관리·메뉴 관리
- 4단계 ✅ 월급 계산(홍보팀장·지국장·총국장)·수당 관리·수당 현황/등록·권한 관리·수당계산기 — 전환 완료 (옛 화면 코드 없음)

## 로그인 계정 관리
- 「관리자 → 권한 관리 → 사람」에서 「+ 사람 추가」 → 이름·이메일·역할·소속 → 등록하면 임시 비밀번호가 나옴 → 본인에게 전달
- 처음 로그인하면 새 비밀번호로 바꿔야 사용 가능
- 비밀번호를 잊으면: 로그인 화면 「비밀번호를 잊었어요」(메일) 또는 관리자가 「비밀번호 초기화」
- 계정 생성·초기화·삭제는 Edge Function `admin-users`(supabase/functions/admin-users)가 처리 — 관리자 역할만 호출 가능
